# Sync an older save's perks to the neural processor (CET)

For a save that bought vanilla perks before SkillDrivenProgression. Paste each
command as one line in the Cyber Engine Tweaks console. **Make a manual save
first**; recording and refunding can't be undone except by reloading.

## 1. Preview

```lua
local p=Game.GetPlayer(); local d=PlayerDevelopmentSystem.GetInstance(p):GetDevelopmentData(p); print(d:SDP_SyncVanillaPerks(0))
```

One line per shard: grade map (`#` all of that grade's perks bought, `+` some,
`-` none, `.` grade has no vanilla perks), the grade already recorded, and what
strict and generous would record.

- **Strict:** highest grade where it and every lower grade are fully bought.
  Matches how shards are recorded in order.
- **Generous:** highest grade with any of its perks bought (gaps filled).

## 2. Record

Strict:

```lua
local p=Game.GetPlayer(); local d=PlayerDevelopmentSystem.GetInstance(p):GetDevelopmentData(p); print(d:SDP_SyncVanillaPerks(1))
```

Generous (use instead of strict):

```lua
local p=Game.GetPlayer(); local d=PlayerDevelopmentSystem.GetInstance(p):GetDevelopmentData(p); print(d:SDP_SyncVanillaPerks(2))
```

Grades only go up. Vanilla perks stay bought, so nothing is lost yet.

## 3. Refund the vanilla perks (optional, recommended)

```lua
local p=Game.GetPlayer(); local d=PlayerDevelopmentSystem.GetInstance(p):GetDevelopmentData(p); print(d:SDP_RefundVanillaPerks())
```

Sells every vanilla perk except Relic perks, so from now on only the processor
grants them. Perks above the recorded grades are lost (they'd have to be
trained). Perk points are not returned: they're disabled in this mod.

Mapping: Deadeye per design/DEADEYE_ORDER.md, shards per
design/other-shard-catalog.json, Vehicle = all five vehicle milestone perks,
Hands Expansion = Ambidextrous. Generated by tools/GeneratePerkSync.py.
